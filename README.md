## 📖 Descrição do Projeto
- O código desenvolve um sistema bancário simples em Python capaz de realizar operações como depósito, saque, transferência e emissão de extrato. O programa resolve o problema do controle básico de movimentações financeiras de uma conta, aplicando validações de segurança e limites de operação.Durante a execução, o sistema também registra o histórico das transações realizadas pelo usuário. Foram aplicados conceitos da disciplina como estruturas de repetição, condicionais, funções, tratamento de erros, listas e validação de dados.

## ▶ Como Executar

- Instale o Python no computador
- Baixe pelo site oficial: Python
- Durante a instalação, marque a opção “Add Python to PATH”.
- Abra o VS Code
- Instale a extensão oficial do Python no VS Code.
- Crie um arquivo Python
- Clique em Arquivo > Novo Arquivo
- Salve com o nome banco.py.
- Cole o código no arquivo
- Copie todo o código e cole dentro do banco.py.
- Execute o programa
- Abra o terminal do VS Code em Terminal > Novo Terminal
- Digite o comando:
- python banco.py
- Use o sistema pelo terminal
- O programa pedirá os dados da conta.
- Depois exibirá o menu:
- A → Extrato
- B → Saque
- C → Transferência
- D → Depósito
- E → Sair

- O sistema funciona como um pequeno banco digital no terminal, permitindo depósitos, saques, transferências e consulta de extrato.
